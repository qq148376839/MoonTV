# 2026-01-19 OrionTV 兼容性资源列表接口修复总结

## 📋 修复背景

通过深入分析 OrionTV 代码发现，OrionTV 显示"没有可用的视频源，请检查设置或联系管理员"错误的根本原因是 MoonTV 的 `/api/search/resources` 接口返回空资源列表。

## 🔍 问题分析

### 核心问题
1. **MoonTV 搜索功能独立化**：不再使用 `config.json` 中的 `api_site` 配置
2. **资源列表接口依赖空配置**：`/api/search/resources` 返回 `config.json` 中的空 `api_site`
3. **OrionTV 依赖资源列表**：用于显示可用视频源和进行源过滤
4. **认证限制搜索接口**：OrionTV 需要在登录前获取资源列表

### 影响范围
- OrionTV 完全无法使用，显示错误提示
- MoonTV Web 端不受影响（不依赖此接口）
- 所有 OrionTV 用户都遇到此问题

## 🔧 修复方案

### 1. 修复资源列表接口 (`src/app/api/search/resources/route.ts`)

**问题**：接口返回空数组
```typescript
const apiSites = await getAvailableApiSites(); // 返回 []
```

**解决方案**：返回基于环境变量配置的固定资源列表
```typescript
const resources = [
  {
    key: 'official',
    name: '官方资源',
    api: process.env.NEXT_PUBLIC_OFFICIAL_SEARCH_URL || 'https://789jx.riowang.win',
    official_parser: true,
  },
  {
    key: 'unofficial',
    name: '非官方资源',
    api: process.env.NEXT_PUBLIC_UNOFFICIAL_SEARCH_URL || 'https://ss.riowang.win',
    official_parser: false,
  },
];
```

### 2. 修复认证中间件 (`src/middleware.ts`)

**问题**：搜索接口需要认证，但 OrionTV 需要在登录前访问

**解决方案**：将 `/api/search` 路径添加到认证跳过列表
```typescript
export const config = {
  matcher: [
    '/((?!_next/static|_next/image|favicon.ico|login|warning|api/login|api/register|api/logout|api/cron|api/server-config|api/decrypt|api/search).*)',
  ],
};
```

## ✅ 修复效果

### 修复前
- ❌ `/api/search/resources` 返回 `[]`
- ❌ OrionTV 显示"没有可用的视频源"错误
- ❌ 无法进行任何搜索和播放操作

### 修复后
- ✅ `/api/search/resources` 返回正确的资源列表
- ✅ OrionTV 正常显示可用视频源
- ✅ 搜索和播放功能完全恢复
