## 2026-01-16 去除 config.json 依赖 + 本地下载/播放回归修复总结

### 背景

- 本轮目标之一是 **不再依赖 `config.json`**（删除后仍可 `pnpm dev` 启动、下载/播放链路可用）。
- 同时需要把 2026-01-15 已修复的本地资源能力（混合代理、自动下载续下、KEY 防盗链/切源黑屏等）在代码层面 **回归稳定**，避免出现“修订丢失/失效”。

### 主要故障现象（本轮修复前）

- **`pnpm dev` 失败**：`scripts/convert-config.js` 强依赖读取 `config.json`，文件缺失直接退出。
- **下载 API 500**：`POST /api/download` 仍尝试从 `SourceConfig` 拉取详情（依赖 `config.json`），导致“获取资源详情失败”。
- **官方资源下载落盘错误**：官方资源 `episodes` 为站外播放页（如 youku `.html`），下载器按“直链文件”落盘，生成 `episode_XX.html`，播放器报 `NotSupportedError`。
- **本地资源切集失效**：播放页在本地播放（`/api/local-video`）时错误跳过 `updateVideoUrl`，导致“无法切换剧集”。
- **KEY 落盘/改写缺失**：本地落盘 m3u8 仍指向远端 key（`#EXT-X-KEY URI="https://gfjx...key_*.key"`），导致本地解密不稳定/切源黑屏风险。

### 已完成修复点（本轮）

#### 1) 完全移除对 `config.json` 的启动依赖

- `scripts/convert-config.js`：`config.json` 缺失时生成最小 `src/lib/runtime.ts`（不再退出）。
- `src/lib/config.ts`：取消 Node runtime 动态读取 `config.json` 的逻辑，统一以 `runtime.ts` 作为编译期配置来源（SourceConfig 可为空）。

#### 2) 下载链路不依赖 SourceConfig / config.json

- `POST /api/download`：
  - 优先使用前端传入 `resource`（含 `episodes/source_type`），避免服务端拉详情依赖 `SourceConfig`。
  - 仅在未提供 `resource` 时，才回退使用旧的 `getAvailableApiSites()/getDetailFromApi`。
- `src/lib/db.client.ts` + `src/app/play/page.tsx`：
  - localStorage 模式自动下载时，将当前 `detail` 作为 `resource` 透传给 `/api/download`。

#### 3) 官方资源（789jx/`source_type=official`）下载正确化：先解析再下载

- `src/app/play/page.tsx`：
  - 以 `SearchResult.source_type` 为主判定官方/非官方；不依赖 `SourceConfig`。
- `src/lib/download-service.ts`：
  - 若 `task.resource.source_type === 'official'`（或 `source==='official'`），每集下载前先走解析 API 获取 `m3u8_url`，再按 HLS 下载。
  - 解析失败时 **不再落盘 `.html`**（避免“可下载但不可播”的坏集）。

#### 4) KEY 防盗链敏感：下载器落盘 KEY + m3u8 改写本地 URI

- `src/lib/download-service.ts`：
  - 解析 `#EXT-X-KEY`，下载 key 到 `episode_XX/key_000.key`；
  - KEY 请求强制 `no-cache`，`Referer=mediaPlaylistUrl`；
  - 写入前后记录 `sha256`，如 hash 变化则告警并覆盖（观测优先+自愈）；
  - 将 m3u8 中 `URI="..."` 改写为 `URI="episode_XX/key_000.key"`。
- `src/app/api/[episode]/[segment]/route.ts`：
  - 支持 `key_000.key` 的读取（原本仅允许 `segment_*.ts`），并返回正确 `Content-Type`。

#### 5) 切集/切源稳定性回归（对应 260115 指南）

- `src/app/play/page.tsx`：
  - 移除非 WebKit 的 `switch` 切源分支，切集/切源统一“销毁并重建” Artplayer + Hls；
  - 删除“本地资源时跳过 updateVideoUrl”的错误优化，保证本地播放也可切集；
  - 倍速恢复不再只限 WebKit（Chrome 也恢复）。

### 关键验证点（建议回归）

- **启动**：删除 `config.json` 后执行 `pnpm dev` 应可启动。
- **官方资源下载**：
  - 下载日志应出现 `解析成功，开始下载 M3U8: https://gfjx.../m3u8/...`；
  - 不应再出现 `下载直接文件: ...youku...html`。
- **KEY 落盘/改写**：
  - 本地 `episode_XX.m3u8` 的 `#EXT-X-KEY URI=` 应为 `episode_XX/key_000.key`；
  - 目录应存在 `episode_XX/key_000.key`。
- **本地切集**：
  - 不应出现“已使用本地资源且 videoUrl 已设置，跳过 updateVideoUrl”；
  - 切集时播放器应进入“销毁并重建”路径（而非 switch）。
