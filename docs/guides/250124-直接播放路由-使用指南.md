## 🎯 功能简介

直接播放路由功能允许您通过 URL 参数直接播放视频，无需经过搜索、详情页等复杂流程。这对于已知视频地址的场景非常有用。

---

## 🚀 快速开始

### 基本用法

访问以下格式的 URL 即可播放视频：

```
/player?url=<视频地址>
```

### 示例

```
/player?url=https://example.com/video.m3u8
```

---

## 📖 详细说明

### URL 参数

- **参数名**：`url`
- **参数类型**：字符串（URL 编码）
- **必填**：是
- **说明**：视频播放地址，支持 m3u8 等播放器已支持的格式

### URL 编码

如果您的视频 URL 包含多个查询参数，需要完整编码：

#### 方法 1：使用浏览器控制台

打开浏览器控制台（F12），运行：

```javascript
encodeURIComponent('https://example.com/video.m3u8?key=xxx&act=.m3u8');
```

复制结果作为 URL 参数。

#### 方法 2：使用在线工具

使用在线 URL 编码工具（如 https://www.urlencoder.org/）进行编码。

#### 方法 3：手动编码

常见字符编码对照：

- `:` → `%3A`
- `/` → `%2F`
- `?` → `%3F`
- `=` → `%3D`
- `&` → `%26`

## ❓ 常见问题

### Q1: 为什么视频无法播放？

**可能原因**：

1. URL 未正确编码（包含多个查询参数时）
2. 视频地址无效或已过期
3. 网络连接问题
4. 视频格式不支持

**解决方法**：

1. 检查 URL 是否正确编码
2. 验证视频地址是否有效
3. 检查网络连接
4. 尝试重试按钮

### Q2: 如何编码包含多个查询参数的 URL？

**方法**：使用 `encodeURIComponent()` 函数完整编码整个 URL。

**示例**：

```javascript
const videoUrl = 'https://example.com/video.m3u8?key=xxx&act=.m3u8';
const encodedUrl = encodeURIComponent(videoUrl);
// 结果：https%3A%2F%2Fexample.com%2Fvideo.m3u8%3Fkey%3Dxxx%26act%3D.m3u8
```

### Q3: 支持哪些视频格式？

**支持格式**：

- m3u8 (HLS)
- 其他播放器已支持的格式

### Q4: 是否需要登录？

**答案**：需要。该功能受现有 middleware 保护，需要登录验证。
