**问题描述**：

**修复方案**：

- ✅ 添加 `isInitializingRef` 跟踪初始化状态
- ✅ 在 `useEffect` 中添加检查，避免重复调用 `updateVideoUrl`
- ✅ 在 `initAll` 开始时设置标志，结束时重置

**修复文件**：

- `src/app/play/page.tsx`

**关键代码**：

```typescript
// 添加初始化标志
const isInitializingRef = useRef(false);

// initAll 中防止重复执行
if (isInitializingRef.current) {
  return;
}
isInitializingRef.current = true;

// useEffect 中检查
if (loading || isInitializingRef.current) {
  return; // 跳过，避免重复调用
}
```

### 2. Edge Runtime 兼容性修复 ⭐ 关键修复

**问题描述**：

- 构建时出现 `eval('require')` 错误：`Dynamic Code Evaluation not allowed in Edge Runtime`
- `process.cwd()` 和 `process.versions` 在 Edge Runtime 中不可用
- `crypto` 模块在 Edge Runtime 中不可用

**修复方案**：

#### 2.1 `config.ts` 修复

- ✅ 添加 `isEdgeRuntime()` 函数检测运行环境
- ✅ 将 `eval('require')` 改为直接使用 `require`（带类型注释）
- ✅ 在 Edge Runtime 中直接使用编译时配置，跳过文件读取
- ✅ 安全地检查 `process.versions`，避免访问未定义属性

**修复文件**：

- `src/lib/config.ts`

**关键代码**：

```typescript
// 检查是否在 Edge Runtime 中
function isEdgeRuntime(): boolean {
  try {
    if (typeof process === 'undefined') {
      return true;
    }
    const versions = (process as any).versions;
    return !versions || !versions.node;
  } catch {
    return true;
  }
}

// Edge Runtime 中直接使用编译时配置
if (isEdgeRuntime()) {
  fileConfig = runtimeConfig as unknown as ConfigFileStruct;
  return;
}

// Node.js Runtime 中使用 require
// @ts-expect-error - require 在 Node.js runtime 中可用
const fs = require('fs') as typeof import('fs');
```

#### 2.2 `decrypt.ts` 修复

- ✅ 移除顶层的 `import crypto from 'crypto'`
- ✅ 添加 `getCrypto()` 函数，仅在 Node.js runtime 中动态加载 crypto
- ✅ 将所有 `crypto.` 调用改为 `getCrypto().`
- ✅ Edge Runtime 中通过 HTTP API 调用解密，不直接使用 crypto

**修复文件**：

- `src/lib/decrypt.ts`

**关键代码**：

```typescript
// 动态导入 crypto 模块
let crypto: typeof import('crypto') | null = null;

function getCrypto(): typeof import('crypto') {
  if (crypto) return crypto;
  if (isEdgeRuntime()) {
    throw new Error('crypto module is not available in Edge Runtime');
  }
  crypto = require('crypto');
  return crypto;
}

// 使用
const decipher = getCrypto().createDecipheriv(...);
```

## 📝 技术细节

### 1. 无限循环修复机制

**问题根源**：

- `initAll` 中调用 `updateVideoUrl`
- `useEffect` 依赖 `detail` 和 `currentEpisodeIndex`，也会调用 `updateVideoUrl`
- 状态更新导致 `useEffect` 重新执行，形成循环

**解决方案**：

- 使用 `isInitializingRef` 跟踪初始化状态
- 在 `useEffect` 中检查初始化状态，避免重复调用
- 在 `initAll` 中设置和重置标志

### 2. Edge Runtime 兼容性机制

**问题根源**：

- Turbopack 在构建时分析代码，发现 `eval('require')` 就报错
- Edge Runtime 不支持 Node.js API（`process.cwd()`, `crypto` 等）

**解决方案**：

- 使用运行时检查 `isEdgeRuntime()` 判断环境
- Edge Runtime 中跳过 Node.js API 调用
- 使用 `require` 代替 `eval('require')`，并添加类型注释
