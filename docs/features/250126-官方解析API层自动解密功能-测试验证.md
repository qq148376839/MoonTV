## 3. 测试用例

### 3.1 单元测试用例

#### 用例 1：decryptEpisodeUrl - 缓存命中

**输入**：

- `parserUrl`: `"https://jx.789jiexi.com"`
- `videoUrl`: `"https://v.qq.com/x/cover/xxx.html"`

**预期**：

- 如果缓存中存在，直接返回缓存的解密结果
- 响应时间 < 1 秒

#### 用例 2：decryptEpisodeUrl - 解密成功

**输入**：

- `parserUrl`: `"https://jx.789jiexi.com"`
- `videoUrl`: `"https://v.qq.com/x/cover/xxx.html"`

**预期**：

- 返回真实的 m3u8 或 MP4 地址
- URL 格式正确（以 `http://` 或 `https://` 开头）
- 结果保存到缓存

#### 用例 3：decryptEpisodeUrl - 解密失败

**输入**：

- `parserUrl`: `"https://jx.789jiexi.com"`
- `videoUrl`: `"https://invalid-url.com"`

**预期**：

- 返回原始 URL（降级处理）
- 不抛出异常
- 记录警告日志

#### 用例 4：decryptEpisodeUrl - 超时

**输入**：

- `parserUrl`: `"https://jx.789jiexi.com"`
- `videoUrl`: `"https://slow-response.com"`

**预期**：

- 10 秒后超时
- 返回原始 URL
- 不抛出异常

#### 用例 5：decryptEpisodeUrls - 批量解密

**输入**：

- `parserUrl`: `"https://jx.789jiexi.com"`
- `videoUrls`: `["https://v.qq.com/1", "https://v.youku.com/2", "https://invalid.com/3"]`

**预期**：

- 并发解密所有 URL
- 成功的返回解密结果，失败的返回原始 URL
- 返回数组顺序与输入一致
- 单个失败不影响其他

### 3.2 集成测试用例

#### 用例 6：searchFromApi - 官方解析资源

**输入**：

- 调用 `/api/search/one?q=测试&resourceId=789caiji`（假设 789caiji 是官方解析源）

**预期**：

- 返回的搜索结果中，`episodes` 字段包含解密后的 m3u8 地址
- 非官方解析资源不受影响
- API 响应时间合理（≤ 15 秒）

#### 用例 7：getDetailFromApi - 官方解析资源

**输入**：

- 调用 `/api/detail?id=xxx&source=789caiji`（假设 789caiji 是官方解析源）

**预期**：

- 返回的详情中，`episodes` 字段包含解密后的 m3u8 地址
- 非官方解析资源不受影响
- API 响应时间合理（≤ 15 秒）

#### 用例 8：错误降级处理

**输入**：

- 调用 API，模拟解密失败场景

**预期**：

- API 正常返回 200 状态码
- `episodes` 字段包含原始 URL
- 不抛出异常

## 6. 手动测试步骤

### 6.1 测试环境准备

1. **启动开发服务器**：

   ```bash
   pnpm dev
   ```

2. **配置官方解析源**：
   在 `config.json` 中确保有官方解析源配置：
   ```json
   {
     "api_site": {
       "789caiji": {
         "api": "https://www.caiji.cyou/api.php/provide/vod",
         "name": "789采集",
         "official_parser": true
       }
     }
   }
   ```

### 6.2 测试步骤

#### 步骤 1：测试 searchFromApi

1. 调用 `/api/search/one?q=测试&resourceId=789caiji`
2. 检查返回结果中的 `episodes` 字段
3. 验证 URL 是否为解密后的 m3u8 地址

#### 步骤 2：测试 getDetailFromApi

1. 从搜索结果中获取一个视频 ID
2. 调用 `/api/detail?id={id}&source=789caiji`
3. 检查返回结果中的 `episodes` 字段
4. 验证 URL 是否为解密后的 m3u8 地址

#### 步骤 3：测试错误处理

1. 模拟解密失败场景（如使用无效的解析器 URL）
2. 验证 API 是否正常返回
3. 验证返回的 URL 是否为原始 URL

#### 步骤 4：测试性能

1. 测试缓存命中时的响应时间
2. 测试批量解密时的响应时间
3. 验证是否符合性能要求
