## 1. 功能概述

官方解析功能已完整实现，支持自动识别和解密加密的视频播放地址，获取真实的 m3u8 或 MP4 播放地址。

### 1.1 核心功能

- ✅ 配置扩展：支持 `official_parser` 字段配置
- ✅ 解密 API：服务端 AES-CBC 解密实现
- ✅ 播放流程集成：自动识别并解密官方解析资源
- ✅ 缓存机制：内存缓存 + 数据库缓存
- ✅ 重定向跟踪：支持跟踪解密后的重定向
- ✅ 多播放源提取：提取所有播放源的所有剧集 URL
- ✅ 错误处理：完善的错误处理和用户提示

## 2. 实现细节

### 2.1 配置扩展

**文件**：`config.json`, `src/lib/config.ts`, `src/lib/admin.types.ts`

**实现**：

- 在 `config.json` 的 `api_site` 配置中添加 `official_parser` 字段
- 类型定义：`official_parser?: boolean`
- 默认值：`false`（缺失时）
- 解析器 URL：使用固定的默认值 `https://jx.789jiexi.com`

**配置示例**：

```json
{
  "api_site": {
    "789caiji": {
      "api": "https://www.caiji.cyou/api.php/provide/vod",
      "name": "789采集",
      "official_parser": true
    }
  }
}
```

### 2.2 搜索阶段 URL 提取

**文件**：`src/lib/downstream.ts`

**实现**：

- 官方解析资源：从 `vod_play_url` 中提取所有播放源的所有剧集 URL
- 格式解析：
  - `$$$` 分隔不同的播放源
  - `#` 分隔同一播放源的多个剧集
  - `$` 分隔剧集名和 URL
- 提取所有第三方视频网站 URL（腾讯、优酷、爱奇艺等）

**示例**：

```
输入：正片$https://v.qq.com/x/cover/xxx.html$$$高清正片$https://v.youku.com/v_show/xxx.html$$$正片$https://www.iqiyi.com/v_xxx.html
输出：[
  "https://v.qq.com/x/cover/xxx.html",
  "https://v.youku.com/v_show/xxx.html",
  "https://www.iqiyi.com/v_xxx.html"
]
```

### 2.3 解密 API 实现

**文件**：`src/lib/decrypt.ts`, `src/app/api/decrypt/route.ts`

**解密流程**：

1. **获取 iframe URL**

   - 访问 `{parserUrl}/?url={videoUrl}`
   - 从 HTML 中提取 iframe 的 src 属性

2. **提取 ConFig 对象**

   - 访问 iframe 页面
   - 从 HTML 中提取 `ConFig.url`（加密的 URL）
   - 从 HTML 中提取 `ConFig.config.uid`（用户 ID）

3. **解密 URL**

   - 密钥生成：`key_str = '2890' + uid + 'tB959C'`
   - 尝试多种密钥/IV 组合：
     - 密钥方式：直接 UTF-8、MD5 哈希、SHA256 前 16/24/32 字节
     - IV 方式：UTF-8 编码(16 字节)、十六进制解析(8 字节)、十六进制解析+填充、重复填充
   - 解密算法：AES-CBC，PKCS7 填充
   - Base64 解码加密 URL
   - 执行 AES 解密
   - 移除 PKCS7 填充

4. **跟踪重定向**
   - 访问解密后的 URL
   - 跟踪 HTTP 重定向（301/302/303/307/308）
   - 检查响应是否为 m3u8 格式（以 `#EXTM3U` 开头）
   - **特殊处理**：如果解密后得到 MP4 格式的试看片段，也返回该 URL

**缓存机制**：

- 内存缓存：Map 结构，1 小时 TTL
- 数据库缓存：如果支持，保存到数据库
- 缓存键：`decrypt:{parserUrl}:{videoUrl}`

### 2.4 播放流程集成

**文件**：`src/app/play/page.tsx`, `src/app/api/server-config/route.ts`

**实现**：

1. **配置加载**

   - 播放页面加载时，从 `/api/server-config` 获取 `SourceConfig`
   - 包含每个源的 `official_parser` 配置

2. **播放 URL 更新**

   - 在 `updateVideoUrl` 函数中检查当前源的 `official_parser` 配置
   - 如果为 `true`，调用 `/api/decrypt` 解密
   - 解密成功后，使用解密后的 URL
   - 解密失败时，显示错误提示

3. **用户体验**
   - 显示解密加载状态（"正在解析视频..."）
   - 显示错误提示（如果解密失败）
   - 允许用户重试或切换其他资源

## 3. 关键修复

### 3.1 修复 `/api/server-config` 路由

**问题**：路由只返回了 `SiteName` 和 `StorageType`，没有返回 `SourceConfig`
**修复**：添加 `SourceConfig` 到返回结果中

### 3.2 修复多播放源提取

**问题**：只提取了第一个播放源，丢失了其他播放源
**修复**：遍历所有播放源，提取所有剧集 URL

### 3.3 修复 MP4 试看片段支持

**问题**：解密后得到 MP4 格式的试看片段时，抛出错误
**修复**：如果解密后得到 MP4 内容，返回该 URL 供播放器播放

### 3.4 修复重定向跟踪

**问题**：重定向跟踪逻辑不完善，无法正确处理所有情况
**修复**：

- 添加详细的重定向跟踪日志
- 支持多种 m3u8 链接提取模式
- 支持从 JavaScript 变量中提取 m3u8 链接
- 优化大文件响应处理（只读取前 1KB 用于检查）

## 5. 已知限制

1. **试看片段**：部分资源解析后只能获取 5 分钟试看片段，无法获取完整视频
2. **解密成功率**：取决于解析网站的稳定性，部分资源可能解密失败
3. **性能**：解密过程需要多次 HTTP 请求，耗时较长（3-10 秒）
