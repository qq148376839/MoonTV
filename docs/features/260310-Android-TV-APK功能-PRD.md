## 1. 背景与目标

### 1.1 业务背景

MoonTV 目前在电视端仅支持通过第三方应用 OrionTV 接入。OrionTV 使用独立的 TV 专用 API（`/api/search/one`、`/api/search/resources`），与 Web 端主流程存在逻辑分歧，导致：

- 本地已下载资源经常无法在电视端正确播放
- Web 端功能更新后 TV 端频繁出问题
- 需要维护两套 API 逻辑，开发成本高

### 1.2 用户痛点

- **播放不一致**：Web 端能播放的资源，电视端通过 OrionTV 经常播放失败
- **本地资源不可用**：服务器上已下载的本地资源无法在电视端正确调用
- **维护成本高**：每次 Web 端更新搜索/播放逻辑，都需要同步适配 OrionTV 的独立 API
- **体验割裂**：电视端缺少收藏、观看历史等与 Web 端一致的功能

### 1.3 业务目标

- **主要目标**：
  - 构建自有 Android TV APK，取代对 OrionTV 的依赖
  - 使用与 Web 端完全相同的 API 和业务逻辑，消除双重维护
  - 电视端正确支持本地已下载资源的优先播放
- **成功指标**：
  - TV 端播放成功率与 Web 端一致（>= 95%）
  - 本地资源在 TV 端正确播放率 >= 98%
  - 功能覆盖：搜索、播放、收藏、观看历史
  - 搜索体验：拼音首字母输入（如 "ls" -> "雷神"）

### 1.4 项目范围

- **包含范围**：
  - TV 专用 Web 页面（`/tv/*` 路由组）
  - D-pad 遥控器焦点导航系统
  - 拼音首字母联想搜索
  - Android TV 外壳应用（WebView + ExoPlayer）
  - ExoPlayer 原生 HLS 视频播放
  - JS - Native 桥接（播放控制与进度回传）
  - 收藏夹和观看历史同步
- **不包含范围**：
  - TV 端管理后台功能（后续迭代）
  - 语音搜索集成（后续迭代）
  - 手机端遥控器/投屏功能（后续迭代）

## 2. 技术方案

### 2.1 方案选择：TV Web 路由 + Android 外壳

| 方案                       | 优点                             | 缺点                   | 维护成本 |
| -------------------------- | -------------------------------- | ---------------------- | -------- |
| TV Web 路由 + Android 外壳 | 同一代码库，同一 API，零逻辑分歧 | WebView 性能受设备限制 | 低       |
| 原生 Kotlin Android TV     | 最佳 TV 原生体验                 | 需维护两套 UI 代码     | 高       |
| 继续使用 OrionTV           | 无需开发                         | 逻辑分歧，维护两套 API | 高       |

**选择理由**：核心需求是"不维护两套逻辑"。TV Web 路由方案在现有 Next.js 项目中添加 `/tv` 页面，使用完全相同的 API 端点，Android 外壳仅负责 WebView 加载和原生视频播放。

### 2.2 架构概览

```
+---------------------------------------------+
|              Android TV APK                  |
|  +------------+      +-------------------+  |
|  |  WebView   |--桥接--|   ExoPlayer       |  |
|  | 加载 /tv/* |      | 原生 HLS 播放     |  |
|  +-----+------+      +-------------------+  |
|        |                                     |
+--------+-------------------------------------+
         | HTTP (同一 API)
+--------+-------------------------------------+
|            MoonTV 服务端 (Next.js)            |
|  /api/search     - 多源聚合搜索               |
|  /api/detail     - 视频详情                   |
|  /api/favorites  - 收藏管理                   |
|  /api/playrecords - 播放记录                  |
|  /api/official-play.m3u8   - 官方源播放       |
|  /api/unofficial-play.m3u8 - 非官方源播放     |
|  /tv/*           - TV 专用 Web 页面           |
+-----------------------------------------------+
```

### 2.3 与 OrionTV 方案对比

| 维度      | OrionTV 方案                    | 自有 APK 方案                    |
| --------- | ------------------------------- | -------------------------------- |
| 搜索 API  | `/api/search/one`（独立）       | `/api/search`（与 Web 共用）     |
| 资源列表  | `/api/search/resources`（独立） | 无需（Web 页面内含）             |
| 播放链路  | OrionTV 客户端解析              | ExoPlayer + 服务端 302 重定向    |
| 本地资源  | 通过独立 API 检测               | 服务端自动处理（302 到本地文件） |
| 收藏/历史 | 不支持                          | 与 Web 端完全同步                |
| 逻辑维护  | 两套                            | 一套                             |

## 3. 功能需求

### 3.1 TV 首页

- Netflix 风格横向滚动行布局
- 行内容：继续观看、热门电影、热门电视剧、热门综艺
- 数据来源：`/api/playrecords`、`/api/douban/categories`
- D-pad 焦点导航：上下切换行，左右滚动行内卡片

### 3.2 TV 搜索

- 拼音首字母联想搜索系统：
  - 输入 "ls" -> 显示 "雷神"、"老师"、"历史" 等候选词
  - 使用 `pinyin-pro` 库进行拼音缩写匹配
  - 字典来源：内置静态字典（热门影视名称） + 搜索历史 + 豆瓣热门
  - 字典定期更新：每次访问首页时从豆瓣数据追加新标题
- SSE 流式搜索结果展示（与 Web 端相同的 `/api/search/stream`）
- 搜索历史快捷选择

### 3.3 TV 详情/播放

- 影片信息展示：海报、标题、年份、简介
- 播放源切换标签
- 集数网格（带下载状态指示）
- 点击集数 -> 通过 JS 桥接调用原生 ExoPlayer 播放
- 播放链接使用与 Web 端完全相同的端点：
  - 官方源：`/api/official-play.m3u8?url=...&source=...&id=...&ep=...&total=...`
  - 非官方源：`/api/unofficial-play.m3u8?source=...&id=...&q=...&url=...&ep=...&total=...`
- 服务端自动处理本地资源优先：已下载 -> 302 到本地文件，未下载 -> 302 到在线流
- 播放结束/退出时回传进度，保存播放记录
- 收藏切换功能

### 3.4 TV 收藏

- 收藏列表网格展示
- 点击进入详情页
- 数据来源：`/api/favorites`

### 3.5 TV 登录

- 大号输入框，遥控器友好
- 使用与 Web 端相同的 `/api/login` 端点
- Cookie 认证在 WebView 中自动生效

### 3.6 Android TV 外壳

- 首次启动：设置服务器地址
- WebView 加载 `{服务器地址}/tv`
- ExoPlayer 原生 HLS 播放（通过 JS 桥接触发）
- Android TV Leanback 启动器集成
- 遥控器按键映射：方向键导航、确认键选择、返回键回退
- ExoPlayer 控制：左右快进快退、中间暂停/播放
